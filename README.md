## 起名流程

八字起名不是凭空想字，灵机遵循一套严谨的分析流程，每一步都有命理依据。

### 第一步：排八字

根据出生年月日时 + 出生地，确定四柱八字，推算日主五行强弱。

### 第二步：定用神

通过扶抑法 + 调候法，确定日主的用神、喜神、忌神。这是起名的命理根基——用神选对了，名字才有补益作用。

### 第三步：康熙字典笔画

严格以康熙字典笔画为准，不取简体字笔画。每个字的五行归属经考据确认，不凭感觉猜测。

### 第四步：三才五格

计算天格、人格、地格、外格、总格的数理吉凶，筛选三才相生的吉祥组合。数理为大凶的组合直接排除，不留隐患。

### 第五步：音韵分析

分析名字的声调搭配，避免音韵不谐。

### 第六步：AI 综合解读

DeepSeek 大模型将以上所有数据转化为自然语言报告，解释每个名字的命理含义、五行补益、数理吉凶。
